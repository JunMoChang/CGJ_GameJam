# 🐱 锚锚向前冲

> **2026 CIGA GameJam 武汉线下站点作品**

---

## 🎮 游戏简介

《锚锚向前冲》是一款以**锚**为主题的休闲策略游戏，核心玩法融合了经典贪吃蛇与格子占领机制。

你操控一只可爱的猫咪在棋盘上移动，**吃鱼长大**、**射击破障**，目标是让你的猫猫**占领棋盘 60% 以上的格子**！

---

## 🕹️ 核心玩法

| 操作 | 说明 |
|------|------|
| 🧭 **移动键（WASD）** | 控制猫咪移动方向 |
| 🔫 **攻击键（Space）** | 发射泡泡子弹，摧毁前方障碍 |
| ⏸️ **暂停键（Esc）** | 暂停 / 继续游戏 |

### 规则

- 🐟 **吃鱼增长**：每吃一条鱼，猫身增长一节，向占领目标迈进
- 🪨 **避开木桶**：撞到木桶或墙壁会直接失败
- 💥 **射击破障**（第3关起解锁）：发射子弹摧毁挡路的木桶
- 🏆 **胜利条件**：猫身长度占棋盘格子数的 **60%** 以上

### 星级评价

| 星星 | 占用率要求 |
|------|-----------|
| ⭐ | ≥ 30%（存活即可） |
| ⭐⭐ | ≥ 45% |
| ⭐⭐⭐ | ≥ 60% |

---

## 🗺️ 关卡设计

游戏共 **5 个关卡**，难度逐步递增：

| 关卡 | 棋盘大小 | 初始木桶 | 特色机制 |
|------|---------|----------|---------|
| 第1关 | 6×6 | 无 | 🌱 入门教学，熟悉基本移动和吃鱼 |
| 第2关 | 8×8 | 无 | 📐 更大棋盘，练习路径规划 |
| 第3关 | 10×10 | 5~10个 | 🔫 **解锁攻击系统** + 攻击教学弹窗 |
| 第4关 | 12×12 | 18~26个 | 💪 更多木桶，考验综合能力 |
| 第5关 | 14×14 | 34个 | 🎲 **随机生成木桶 + 高密度木桶**，每次移动都可能出现新障碍 |

## 🎨 美术风格

- **主题**：猫咪海盗 / 猫咪冒险
- **棋盘**：双色棋盘格（白色 + 暖黄色）
- **角色**：带枪猫咪头像、猫身体、猫尾巴、转角身体（支持视觉转向）
- **食物**：三种不同颜色的小鱼 🐟
- **障碍**：木桶 🛢️ + 碎木板 🪵
- **UI**：手绘风格装饰元素（小鱼挂牌、小猫挂牌、星星评级）
- **动态背景**：主菜单和游戏中均有视频背景

---

## 🔊 音频

- 🎵 **多场景 BGM**：开始画面、主菜单、游戏中各有专属背景音乐
- 🔈 **音效反馈**：吃鱼音效、攻击音效、胜利/失败音效
- ⚡ **攻击音效预加载**：降低射击延迟感

## 🛠️ 技术实现

| 技术点 | 说明 |
|--------|------|
| **引擎** | Unity (URP 2D) |
| **输入系统** | Unity New Input System |
| **关卡配置** | ScriptableObject 数据驱动 |
| **架构模式** | 单例 + 事件驱动 |
| **命名空间** | `Core` / `Grid` / `Snake` / `Gameplay` / `UI` / `Audio` / `Config` |
| **字体** | 思源黑体 (Source Han Sans SC) |
| **文本渲染** | TextMesh Pro |

### 代码架构

```
Assets/Scripts/
├── Core/           # 核心：GameManager（游戏状态机）
├── Grid/           # 网格系统：GridManager、格子状态枚举
├── Snake/          # 蛇控制器：移动、攻击、视觉渲染、子弹
├── Gameplay/       # 游戏逻辑：关卡生成、食物管理、岩石管理、相机适配
├── Config/         # 数据配置：LevelConfig、LevelDatabase (ScriptableObject)
├── UI/             # 界面：主菜单、HUD、结算面板、暂停遮罩、教学弹窗
└── Audio/          # 音频：BGM管理、音效、菜单视频背景
```
